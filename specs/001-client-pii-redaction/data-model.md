## Entities & Type Definitions

### 1. `RedactionCategory` (Enumeration)
Defines the standard taxonomy of personally identifiable information governed by the privacy boundary:
- `FINANCIAL`: Payment cards (15–19 digits, Luhn validated), bank account numbers, CVVs.
- `IDENTITY`: National IDs (US SSN, Indian PAN, Aadhaar Verhoeff validated), passport numbers, tax IDs.
- `CONTACT`: Email addresses, telephone numbers, postal addresses.
- `CREDENTIAL`: Passwords, PINs, auth tokens, session cookies, API secrets.
- `BIOMETRIC_VISUAL`: Human faces, photographic portraits, signature canvases.

---

### 2. `SemanticToken` (Enumeration & Mapping)
Fixed, uniform placeholder strings substituted in serialized payloads.
```typescript
export enum SemanticToken {
  FINANCIAL = "<REDACTED_FINANCIAL>",
  IDENTITY = "<REDACTED_IDENTITY>",
  CONTACT = "<REDACTED_CONTACT>",
  CREDENTIAL = "<REDACTED_CREDENTIAL>"
}
```
*Validation Rules*:
- Tokens MUST be constant length per category.
- Tokens MUST NEVER be written into the live document DOM.
- Tokens MUST ONLY exist in memory and serialized outbound payloads.

---

### 3. `BoundingBox`
Represents the geometric viewport coordinates of a protected or rendered element.
```typescript
export interface BoundingBox {
  x: number;

  width: number;
  height: number;
  top: number;
  left: number;
  bottom: number;
  right: number;
}
```

---

### 4. `DetectedEntity`
Represents a distinct PII instance identified during the local perception pass.
```typescript
export interface DetectedEntity {
  id: string;                      // Unique entity UUID
  category: RedactionCategory;     // Classification
  token: SemanticToken;            // Assigned replacement token
  nodeId: string;                  // Structural node identifier in DOM snapshot
  selector?: string;               // CSS selector / XPath for live DOM element
  bounds: BoundingBox;             // Viewport coordinates for audit overlay
  associatedLabelNodeIds: string[]; // Adjacent descriptor labels to scrub
  confidence: number;              // Detection confidence (0.0 - 1.0)
  verified: boolean;               // Whether sanitization was confirmed
}
```
*Validation Rules*:
- `confidence` must be ≥ 0.80 for positive classification; otherwise default to redacted if ambiguous.
- `associatedLabelNodeIds` must contain all associated `<label>`, `aria-labelledby`, and preceding text sibling IDs within 50px spatial proximity.

---

### 5. `RedactionManifest`
An internal verification contract generated by the background privacy boundary for each perception cycle.
```typescript
export interface RedactionManifest {
  cycleId: string;                 // Cycle identifier
  timestamp: string;               // ISO 8601 timestamp
  scopeTier: "TIER_1_CORE_EXTENDED" | "TIER_2_CORE_ONLY";
  entities: DetectedEntity[];      // All identified sensitive entities
  totalDetected: number;           // Count of entities
  labelsScrubbedCount: number;     // Count of adjacent descriptor labels removed
  verificationStatus: "PENDING" | "VERIFIED" | "FAILED";
  checksum: string;                // Cryptographic or hash signature of manifest state
}
```
*Validation Rules*:
- `verificationStatus` must be set to `VERIFIED` ONLY after outbound serialization passes the zero-leakage scanner.
- If `verificationStatus === 'FAILED'`, the payload MUST be dropped and a `PrivacyAbortEvent` emitted.

---

### 6. `SanitizedPayloadEnvelope`
The strictly controlled outbound network payload sent to the remote VLM reasoning service.
```typescript
export interface SanitizedPayloadEnvelope {
  schemaVersion: "1.5.0";
  cycleId: string;
  tokenManifest: SemanticToken[];  // Distinct token types present in payload
  sanitizedDomTree: SanitizedDomNode; // Structural hierarchy with coordinates and tokens
  metrics: {
    sanitizationDurationMs: number;
    entitiesRedactedCount: number;
  };
}

export interface SanitizedDomNode {
  nodeId: string;
  tag: string;                     // HTML tag or ARIA role (e.g., 'input', 'button')
  role?: string;                   // Cleaned ARIA role
  bounds: BoundingBox;             // Non-sensitive layout coordinates
  text?: string;                   // Sanitized text content (contains <REDACTED_*> tokens)
  attributes?: Record<string, string>; // Sanitized non-sensitive attributes (type, disabled)
  children?: SanitizedDomNode[];
}
```
*Validation Rules*:
- `schemaVersion` must match the server-side VLM parser specification (`1.5.0`).
- `sanitizedDomTree` must contain 0 unmasked regex matches for sensitive categories.
- No binary image data, raw canvas pixel arrays, or plaintext PII strings permitted anywhere in the object.

### 7. `AuditOverlayMarker`
Represents an individual visual indicator rendered in the user's browser viewport.

```typescript
export interface AuditOverlayMarker {
  entityId: string;
  bounds: BoundingBox;
  category: RedactionCategory;
  color: string;                   // Indicator border/fill color
  label: string;                   // Non-sensitive indicator text (e.g., 'Protected: Financial')
}
```

---

### 8. `PrivacyAbortEvent`
The fail-closed halt trigger emitted when verification fails.
```typescript
export interface PrivacyAbortEvent {
  eventType: "PRIVACY_ABORT";
  cycleId: string;
  timestamp: string;
  reason: string;                  // Diagnostic message (e.g., "Verification failed: residual PII detected")
  failedStage: "DETECTION" | "TOKENIZATION" | "VERIFICATION" | "TIMEOUT";
  actionRequired: "HALT_TASK_SESSION";
}
```

## State Lifecycle & Transitions

```
[ Page DOM State ]
       │
       ▼
 [ 1. Observe & Extract ] (Capture DOM tree + geometry)
       │
       ▼
 [ 2. Normalize & Detect ] (NFKC, Homoglyphs, Regex, Checksums, Label Association)
       │
       ▼
 [ 3. Build Manifest ] (Create RedactionManifest with entities & bounds)
       │
       ▼
 [ 4. Structural Tokenize ] (Inject <REDACTED_*> tokens into serialized tree, scrub labels)
       │
       ▼
 [ 5. Pre-Transmission Verification ]
       ├── [ Fail / Leak Detected / Timeout ] ──► [ Emit PrivacyAbortEvent ] ──► HALT SESSION
       │
       └── [ Pass: 0 Plaintext PII ]
             │
             ├──► [ Asynchronously Paint Audit Overlay ] (<=50ms budget)
             │
             └──► [ Attach Header & Serialize Envelope ] ──► Transmit to VLM
```
